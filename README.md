# Azam Finance — бюджет организации

Веб-приложение для учёта бюджета проектной организации: доходы и расходы,
проекты (объекты проектирования) с договорами и долгами заказчиков,
заказчики, сотрудники и зарплаты, отчёты по периодам.

## Как запустить

Приложение полностью локальное, отдельный сервер не нужен.

- Дважды кликните **`Запустить.bat`** — откроется в браузере по умолчанию.
- Либо откройте **`index.html`** напрямую (дважды кликните по файлу).

Работает в любом современном браузере (Chrome, Edge, Firefox). Интернет
нужен только для загрузки шрифтов — без него приложение тоже работает,
просто шрифты подставятся системные.

## Где хранятся данные

Все операции, проекты, заказчики и сотрудники сохраняются **в этом
браузере**, на этом компьютере (localStorage). Данные не отправляются
никуда в интернет и не синхронизируются между разными браузерами или
устройствами автоматически.

Из этого следуют два важных момента:

1. Если открыть `index.html` в другом браузере или на другом компьютере —
   там будет пусто. Чтобы перенести данные, используйте экспорт/импорт
   (см. ниже).
2. Очистка истории/данных браузера удалит и записи бюджета. Делайте
   резервные копии регулярно.

## Вход по паролю

При первом запуске приложение попросит задать пароль. Дальше он будет
запрашиваться при каждом открытии (пока не нажмёте «Выйти» на панели слева).

**Важно понимать ограничение:** это защита от случайного доступа (например,
если за компьютер сядет кто-то ещё), а не от целенаправленного взлома.
Приложение работает без сервера, поэтому пароль проверяется прямо в
браузере — человек, открывший консоль разработчика (F12), технически
может обойти экран входа. Для данных, которые нельзя раскрывать ни при
каких обстоятельствах, такой защиты недостаточно.

Сменить пароль можно в **Настройки → Безопасность**.

## Резервные копии

В разделе **Настройки → Хранение данных и резервные копии**:

- **«Скачать резервную копию»** — сохраняет все данные в один `.json`-файл.
  Держите такие файлы в надёжном месте (папка с бэкапами, облачный диск и т.п.).
- **«Восстановить из файла»** — полностью заменяет текущие данные
  содержимым выбранного `.json`-файла. Используется для переноса данных
  на другой компьютер/браузер или для отката к более ранней копии.

Рекомендуется делать резервную копию не реже одного раза в неделю и
обязательно перед сменой компьютера или браузера.

## Структура файлов

```
index.html        — точка входа, структура страницы
css/style.css      — все стили
js/app.js          — вся логика приложения (данные, экран, диалоги)
Запустить.bat      — ярлык для быстрого запуска в Windows
```

## Происхождение

`nemat-budget.html` в этой же папке — исходный вариант приложения под
прежним названием («Неъмат 2010»), изначально созданный как Claude
Artifact с облачной синхронизацией данных через Claude.ai. Текущая
версия (`index.html` + `css/` + `js/`) — самостоятельное локальное
приложение под названием Azam Finance, без зависимости от Claude.ai:
та же функциональность, но данные хранятся только в браузере. Исходный
файл оставлен как резервная копия и может быть удалён, если не нужен.
